**EchoNote 1.0.5: fixes for the recording shortcut and the popup.**

- **Fixed: the recording popup disappeared mid-recording.** If an earlier note finished organizing while you were recording, the popup was hidden after 4 seconds and then reappeared. It now stays visible for the whole recording.
- **Fixed: the GNOME keyboard shortcut could be redirected.** Another EchoNote instance running with a separate data directory (for example the test suite) could rewrite the desktop-wide GNOME shortcut to point at itself. The shortcut then took the slow path, about 2–3 s per press, which invited double presses. Now only the normal profile manages the shortcut, and it repairs the shortcut when it starts.

**Upgrade:** quit EchoNote (Settings → Quit EchoNote completely), install, then start it once. It re-points the GNOME shortcut at the installed app.
```bash
sudo dnf install ./echonote-1.0.5.x86_64.rpm          # Fedora
sudo apt install ./echonote_1.0.5_amd64.deb           # Debian / Ubuntu
chmod +x EchoNote-1.0.5-x86_64.AppImage && ./EchoNote-1.0.5-x86_64.AppImage   # anything else
```
Includes everything from 1.0.4: the .deb package, portable AI runtimes (glibc 2.34+), the top-bar recording indicator, silence auto-stop, and Gemma 4 E2B running locally.
