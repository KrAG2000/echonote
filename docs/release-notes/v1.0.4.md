**EchoNote 1.0.4: a .deb package for Debian/Ubuntu, and AI runtimes that work beyond Fedora.**

- **New: `.deb` package** for Debian / Ubuntu, alongside the Fedora `.rpm` and the portable AppImage. Like the RPM, it adds an app-menu entry and AppStream metadata, so EchoNote shows up in GNOME Software / App Center and can be uninstalled there.
- **Portable AI runtimes.** whisper.cpp and llama.cpp are now compiled in Ubuntu 22.04 with static libstdc++. Before this, the bundled runtimes needed Fedora 44's glibc 2.43, so transcription and AI would not start on Ubuntu or Debian. They now need glibc 2.35 or newer: Ubuntu 22.04+, Debian 12+, Fedora 36+.
- Verified in a clean Ubuntu 24.04 container: the `.deb` installs with apt, and its bundled whisper-server and llama-server transcribe and classify with the real models.
- **One command builds everything:** `npm run dist:linux` builds, inspects and checksums all three packages.

**Install**
```bash
sudo dnf install ./echonote-1.0.4.x86_64.rpm          # Fedora / RHEL
sudo apt install ./echonote_1.0.4_amd64.deb           # Debian / Ubuntu
chmod +x EchoNote-1.0.4-x86_64.AppImage && ./EchoNote-1.0.4-x86_64.AppImage   # anything else
```
Everything runs locally (whisper.cpp + Gemma 4 E2B via llama.cpp). The first launch downloads the models (2.7 GB) once. Requirements: x86-64 CPU with AVX2, ~4.5 GB free RAM.

Uninstall: GNOME Software → Installed → EchoNote → Uninstall, or `sudo dnf remove echonote` / `sudo apt remove echonote`.
